Como disponibilizar o executável direto no site (sem GitHub)

  1. Execute o build: npm run build:win
  2. Os arquivos gerados ficam em dist/ (ex: "MeuPlayer Setup 1.0.0.exe" e "MeuPlayer 1.0.0.exe").
  3. Copie/renomeie para nomes consistentes:
    • dist/MeuPlayer 1.0.0.exe → public/downloads/MeuPlayer-Portable.exe
    • dist/MeuPlayer Setup 1.0.0.exe → public/downloads/MeuPlayer-Setup.exe
  4. Os arquivos em public/downloads/ são ignorados pelo git (veja .gitignore).
  5. Sincronize a pasta para o VPS (via seu fluxo do forja ou scp/rsync) e faça redeploy.
  6. A página /downloads vai servir os arquivos diretamente (sem redirecionar para GitHub).

Dica: o Portable é o mais prático para uso em múltiplos computadores (só baixa e roda).
