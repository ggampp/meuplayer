Use o MeuPlayer em qualquer computador sem clonar o repositório.

Usar no navegador (qualquer computador)

A versão web roda direto no seu VPS. Basta abrir o endereço no navegador. É a forma mais rápida de usar em outro PC, notebook ou celular.

Abrir MeuPlayer agora

Recomendado para uso casual ou quando você não quiser instalar nada.

Baixar o aplicativo desktop completo

Experiência completa com bloqueio de popups, troca de canais por teclado, simulação automática de play e melhor integração com o controle remoto. Recomendado se você usa bastante a aba de TV ao vivo.

Carregando downloads...

Os links acima apontam para a última release no GitHub.
Atualize o owner/repo no package.json e gere novas releases com npm run build:win (ou linux/mac). Coloque os arquivos em public/downloads/ (ignorados pelo git) para hospedagem própria.

Como atualizar os downloads no seu site

  1. Faça o build: npm run build:win (ou linux).
  2. Os artefatos ficam em dist/.
  3. Coloque os arquivos desejados em public/downloads/ (esta pasta é ignorada pelo git).
  4. Ou simplesmente atualize os links acima apontando para a sua release mais recente.
  5. Rebuild e redeploy do Docker para que a página /downloads reflita as mudanças.

Dica: o arquivo portable é o mais conveniente para uso pessoal em vários computadores.
