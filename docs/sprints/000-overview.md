# Princípios e restrições

- Priorizar alto impacto: usar o app em qualquer computador sem clonar o repo.
- Dupla função: VOD (TMDB + player imersivo) e Live TV (workbench).
- Design system travado: `design.md`.
- Versão web (Docker/VPS) + desktop (Electron).
- Electron = melhor experiência Live (popups, atalhos, autoplay).
- `public/downloads/` permanece no Git para distribuição direta do site.
